FLYING COBBLER SUSTAINABILITY STORY PAGE — STARTER FILES

What this is:
- A mobile-friendly web page.
- Customers can upload a footwear photo.
- It generates a vertical 1080 x 1920 sustainability card.
- Customers can download the card or use available sharing options.

Important before publishing:
1. This starter uses the words FLYING COBBLER as a temporary text logo. Replace it with the official logo image when available.
2. The SDG 12 badge is a simplified text badge, not the official UN artwork. Use official SDG 12 artwork only if you have the appropriate asset and follow its usage guidelines.
3. The page runs in the customer's browser and does not upload photos to a server.
4. Test on both Android and iPhone. Instagram/Facebook/WhatsApp may require the customer to choose the image inside the social app; websites cannot guarantee automatic posting to Stories/Status.
5. Check the wording and image design before public launch.

HOW TO PUBLISH ON GODADDY (high-level):
- Best option: ask the person who manages your GoDaddy website to publish this as a separate page/subdomain such as story.flyingcobbler.com.
- Give them index.html and ask them to upload it to a separate folder or configure the subdomain's web root to this page.
- If your existing site is built with WordPress or a website builder, do not overwrite existing website files. Ask the site manager to add it as a separate page or subdomain.
- Once published, test the link on a phone using mobile data and Wi-Fi before sending it to customers.
